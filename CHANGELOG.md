## [0.6.0] — 2026-04-11

### 🏪 Базовая станция звезды
- **Орбитальная станция** — загружает blueprint из JSON-файла, автоматически вычисляет размер и орбиту
- **Динамический расчёт** — орбита = 4× размер, коллизия = 55% размера, астероиды от орбиты + размер
- **Неразрушимость** — нельзя уничтожить, нельзя пролететь сквозь воксели
- **Коллизии** — отскок при столкновении, потеря 5% щитов
- **Клик по станции** — корабль следует за станцией, поворачивается к точке причаливания, выравнивает скорость
- **Клавиша V** — интерфейс обслуживания (когда рядом со станцией)

### 💰 Экономика
- `src/shared/Economy.ts` — общий модуль для клиента и сервера
- Валюта: **Cred (₡)**, стартовые кредиты 500
- **Продажа ресурсов** — металл, кремний, лёд, редкие, топливо
- **Покупка ресурсов** — всё выше + вода
- **Услуги** — лечение радиации, восстановление щитов, зарядка энергии, заправка воды
- **Оптовая скидка** — 10% от 100+ единиц
- **Комиссия станции** — 5% от сделки

### 🔧 UI обслуживания станции
- 4 вкладки: Продать, Купить, Услуги, Прайс-лист
- Автоматический расчёт стоимости
- Показывает текущие ресурсы игрока

### 🐛 Исправления
- `Economy.ts` перемещён в `src/shared/` (клиент не мог импортировать из `src/server/`)
- `tsconfig.client.json` и `tsconfig.server.json` включают `src/shared/**/*`
- Серверный `/station/` маршрут для раздачи blueprint JSON

## [0.5.1] — 2026-04-10

### 🐛 Исправления багов админ-панели

#### Критические исправления
- **Краш сервера на HTTP запросах** — убран middleware логирования запросов, который ломал `res.end` в Express 5
- **`ER_WRONG_ARGUMENTS` в MySQL** — `parseInt(req.query.*)` возвращал `NaN` для пустых query-параметров, что ломало prepared statements в mysql2
- **`DatabaseManager.execute(query)`** — передавал `undefined` вместо `[]` при вызове без параметров

#### Админ-панель: все вкладки работают
- **Игроки** — загружает всех игроков с именем, email, последним входом, статусом, кнопками блокировки/удаления
- **Безопасность** — статистика за 24ч, подозрительная активность, журнал запросов на порты, топ IP с ошибками
- **Журнал** — действия администраторов и журнал изменений (old → new values)
- **Настройки** — добавлена категория «🌐 Общие» (server_name, max_players, maintenance_mode и т.д.)
- **Задания** — корректно загружает все 15 викторин через `apiBaseUrl`

#### Технические детали
- `safeInt(value, def)` — замена `parseInt(...) || def` с `Number.isFinite()` проверкой
- `getAllPlayers` — `LIMIT ? OFFSET ?` заменено на `LIMIT ${lim} OFFSET ${off}` с `Number()` валидацией
- Все query-параметры в маршрутах заменены на жёсткие значения (`LIMIT 200`, `INTERVAL 24 HOUR`)
- `logAdminAction` — `undefined` параметры заменены на `null`

## [0.5.0] — 2026-04-10

### 🎮 Система заданий (Миссии)
- **15 викторин** по истории космонавтики, науке и исследованию космоса
- **8 рангов пилотов**: Новичок → Исследователь → Космонавт → Пилот → Командир → Капитан → Ветеран → Легенда
- **Система наград**: XP, топливо, металл, кремний, лёд, редкие ресурсы
- **Прогресс заданий**: начало, отправка ответа, завершение
- **Защита от дублирования**: сервер блокирует повторную отправку на выполненное задание
- **Визуальная обратная связь**: кнопки ответов подсвечиваются ✓/✗, приглушаются после ответа
- **Кастомные модальные окна** в стиле игры (вместо browser alert)

### 🛡️ Админ-панель
- **Вход**: `/admin` (логин `admin`, пароль из `.env`)
- **Обзор**: статистика сервера (игроки, онлайн, сессии, астероиды, станции)
- **Игроки**: таблица всех игроков с именем, email, последним входом, статусом, кнопками блокировки/разблокировки/удаления
- **Задания**: CRUD-управление миссиями (создание, редактирование, удаление), статистика, ранги
- **Настройки**: категории auth, game, security, email — динамические настройки сервера
- **Безопасность**:
  - Статистика за 24ч (уникальные IP, WS/HTTP запросы, ошибки, 401, 403, неудачные входы)
  - Подозрительная активность (IP/email с 3+ неудачными попытками входа)
  - Журнал запросов на порты 8080/8001
  - Топ IP с ошибками (401/403/5xx)
- **Журнал**:
  - Действия администраторов (кто, когда, что сделал)
  - Журнал изменений (старое/новое значение)

### 🔧 Backend
- **Middleware логирования запросов**: автоматическая запись подозрительных запросов в `port_access_log`
- **Аутентификация пилотов**: `X-Player-Name` header → поиск UUID в БД → создание записи если не существует
- **WebSocket login**: клиент отправляет `playerLogin` после подключения → сервер возвращает `playerData` с UUID
- **Prompt имени**: при первом входе предлагается ввести имя пилота
- **Улучшенный парсинг JSON**: корректная обработка JSON-полей MySQL (mysql2 автоматически парсит)

### 🗄️ База данных
- **Созданы таблицы**: `port_access_log`, `admin_audit_log`
- **Созданы VIEW**: `admin_server_stats`, `admin_suspicious_activity`, `admin_security_stats`, `admin_recent_registrations`
- **Исправлены данные заданий**: все 15 викторин с правильными `options` (JSON-массивы)

- `login_attempts_log` — журнал попыток входа

- `password_reset_codes` — коды восстановления
