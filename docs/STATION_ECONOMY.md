# 🏪 Экономика станции CosmoCraft

## Обзор

Станции служат центрами экономики для игроков. Игроки должны заполнять станции ресурсами, что позволяет развивать экономику и производить товары.

---

## 🏗️ Строительство станций

### Текущее состояние

**Кнопки модулей временно отключены:**
- ❌ Солнечные панели (не доступны)
- ❌ Турели (не доступны)

**Причина:** Экономика станции требует предварительного заполнения ресурсами.

### Будущая реализация

Строительство модулей станет доступным после:
1. Настройки экономики станции
2. Заполнения станции базовыми ресурсами
3. Установки торговых связей

---

## 🚀 Ракеты

### Производство

Ракеты производятся **на станции**, а не на корабле.

**Требования:**
- Станция должна иметь модуль производства ракет
- Игрок должен сдать редкоземельные ресурсы на станцию

### Редкоземельные ресурсы

**Типы:**
- 🌟 Редкие элементы (rare)
- 💎 Кремний (silicon) — частично

**Использование:**
```
10 редких элементов → 1 ракета
5 кремния → 1 ракета (дополнительно)
```

### Лимит ракет

**Чем больше ресурсов сдашь, тем больше ракет сможешь взять:**

| Сдано ресурсов | Макс. ракет |
|----------------|-------------|
| 10 редких | 1 |
| 50 редких | 5 |
| 100 редких | 10 |
| 500 редких | 50 |

**Механика:**
1. Игрок сдаёт ресурсы на станцию
2. Станция производит ракеты
3. Игрок может взять ракеты со склада станции
4. Лимит зависит от вклада игрока

## 💰 Экономика (задел на будущее)

### Игровая валюта

**Планируется:**
- **Кредиты (CR)** — основная валюта
- **Ресурсы** — товарная валюта
- **Репутация** — социальная валюта

### Обмен

**Возможности:**
1. **Ресурсы ↔ Кредиты** — продажа/покупка
2. **Кредиты ↔ Модули** — покупка оборудования
3. **Ресурсы ↔ Ракеты** — производство
4. **Игрок ↔ Игрок** — торговля через станции

### Хранение

**Профили игроков:**
```
players/
└── {playerName}/
    ├── resources.env    # Настройки
    ├── stats.json       # Статистика
    ├── saves.json       # Сохранения
    └── economy.json     # Экономика (будущее)
        ├── credits
        ├── reputation
        ├── stationStock
        └── tradeHistory
```

**Изоляция:**
- Каждый игрок хранит данные в своей папке
- Нельзя перезаписать чужие станции
- Торговля через защищённые API

## 🔄 Торговля

### Станция как торговый центр

**Услуги:**
1. **Пополнение воды** — бесплатно
2. **Заправка энергией** — от звезды
3. **Покупка ракет** — за редкоземы
4. **Продажа ресурсов** — за кредиты (будущее)
5. **Покупка модулей** — за кредиты (будущее)

### Цены (планируется)

| Товар | Цена |
|-------|------|
| Вода | Бесплатно |
| Энергия | Бесплатно (от звезды) |
| Ракета | 10 редких |
| Солнечная панель | 200 CR |
| Турель | 800 CR |
| Металл | 10 CR/ед |
| Кремний | 15 CR/ед |
| Лёд | 8 CR/ед |
| Редкие | 100 CR/ед |

## 📊 Балансировка

### Добыча ресурсов

**Время добычи:**
```
1 астероид → 3-5 выстрелов → 3-10 вокселей
10 вокселей льда → 50 воды
```

**Производительность:**
- Лазер: 1 выстрел / 0.15 сек
- Ваккуум: 1 воксель / 0.5 сек (при открытом люке)

### Расход

**Двигатели:**
- 100% тяга: 1 вода / сек
- 50% тяга: 0.5 вода / сек

**Ракеты:**
- 1 ракета = 10 редких
- Производство на станции

## 🎮 Геймплей

### Цикл игры

```
1. Добыча ресурсов на астероидах
2. Сдача ресурсов на станцию
3. Производство ракет на станции
4. Использование ракет для защиты/атаки
5. Заработок кредитов
6. Покупка улучшений
7. Расширение станции
```

### Стратегия

**Ранняя игра:**
- Добывай лёд для воды
- Собирай металл для базовых нужд
- Избегай трат

**Средняя игра:**
- Сдавай редкоземы на станцию
- Копи ракеты
- Расширяй станцию

**Поздняя игра:**
- Торговля с другими игроками
- Покупка дорогих модулей
- Строительство флота

## 🔐 Безопасность

### Изоляция профилей

**Каждый игрок:**
- Имеет свою папку `players/{name}/`
- Хранит свои сохранения
- Не может изменить чужие данные

**Станции:**
- Принадлежат игроку
- Хранятся в папке игрока
- Нельзя удалить чужую станцию

### API (будущее)

```typescript
// Защищённые эндпоинты
POST /api/player/:name/trade
PUT /api/player/:name/station
GET /api/player/:name/economy
```

## 📝 Интеграция

### Сохранение экономики

```typescript
// При сохранении игры
const saveData = {
    position: this.shipPosition,
    cargo: this.cargo,
    energy: this.energy,
    water: this.water,
    economy: {
        credits: this.credits,
        stationStock: this.stationStock,
        rockets: this.rockets
    }
};

saveGame(playerName, saveData);
```

### Загрузка экономики

```typescript
// При загрузке профиля
const profile = loadPlayerProfile(playerName);
this.credits = profile.economy?.credits || 0;
this.stationStock = profile.economy?.stationStock || {};
```
