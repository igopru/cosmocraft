# 🏪 Базовая станция — Экономика и обслуживание

## Обзор

Базовая станция звезды — орбитальная станция, которая вращается вокруг звезды и предоставляет пилотам услуги: торговлю ресурсами, лечение, заправку и ремонт.

**Версия:** 0.5.1

---

## 🛰️ Расположение

| Параметр | Значение |
|----------|----------|
| Орбита | 4 × максимальный размер станции |
| Зона коллизий | 55% от максимального размера |
| Зона взаимодействия | 30% орбиты + 50 единиц |
| Зона подсказки | 50% орбиты + 100 единиц |
| Астероиды начинаются от | Орбита + размер станции |

### Динамический расчёт

При запуске сервер загружает blueprint станции и автоматически вычисляет:

```
Размер = max(dx, dy, dz) воксельной сетки × 6
Орбита = Размер × 4
Коллизия = Размер × 0.55
Мин. астероид = Орбита + Размер
```

Для SolarWheel_Pro (384 единицы):
- Орбита: **1536 единиц**
- Коллизия: **211 единиц**
- Астероиды от: **1920 единиц**

## 🎮 Управление

| Клавиша | Действие |
|---------|----------|
| **V** | Открыть/закрыть сервис станции |
| Клик мышкой по станции | Причалить (следование за станцией) |

### Коллизии

- Станция — **неразрушимый** объект
- При столкновении: отскок, потеря 5% щитов, cooldown 500мс
- Нельзя пролететь сквозь воксели станции
