# 🎮 Руководство игрока CosmoCraft

## 🚀 Быстрый старт

Добро пожаловать в CosmoCraft — космическую стратегию с видом от первого лица!

### Первые шаги

1. **Вы в космосе** — корабль висит над звездой
2. **Нажмите `A`** — увеличьте тягу
3. **Стрелки** — поверните корабль
4. **Летите!** — корабль следует за направлением носа

---

## 🎯 Управление кораблём

### Вращение (выбор направления)

| Клавиша | Действие |
|---------|----------|
| `←` (стрелка влево) | Поворот носа **влево** |
| `→` (стрелка вправо) | Поворот носа **вправо** |
| `↑` (стрелка вверх) | Нос **вверх** (от звезды) |
| `↓` (стрелка вниз) | Нос **вниз** (к звезде) |

### Движение (тяга)

| Клавиша | Действие |
|---------|----------|
| `A` | **Увеличить тягу** (+10%) |
| `Z` | **Уменьшить тягу** (-10%) |
| `Backspace` | **Сброс скорости** (тяга = 0) |

**Важно:** Корабль летит **туда, куда смотрит нос**!

### Системы корабля

| Клавиша | Действие |
|---------|----------|
| `Ctrl` | 🔥 Лазер (добыча ресурсов) |
| `O` | 🚪 Открыть/закрыть грузовой люк |
| `K` | 🛰️ Развернуть спутник (50 металла) |
| `H` | 🛰️ Отозвать спутники |
| `Tab` | ⚡ Турбо режим (x2 скорости) |
| `J` | ⏱️ S.E.T.A (x5 скорости) |
| `Shift+J` | ⚡ S.E.T.A Boost (x10) |

## 📊 Интерфейс (HUD)

### Внизу слева

```
⚡ [=====>    ] 500/1k    💧 [==========] 100/100
```

- **Энергия** — нужна для двигателей и лазера
- **Вода** — расходуется двигателями

### Вверху справа

```
☢️ РАДИАЦИЯ  [==>       ] 20%
```

- Показывается только при радиации > 0%
- Растёт near звезды

### Внизу справа

┌─────────────────────────────┐

│ 📦 Всего: 100 ед.           │
│ 🚪 Люк: ЗАКРЫТ              │
└─────────────────────────────┘

## ⛏️ Добыча ресурсов

### Шаг 1: Найдите астероид

- **Металлические** — серые
- **Кремниевые** — синие
- **Ледяные** — голубые
- **Редкие** — оранжевые

### Шаг 2: Стреляйте лазером

1. Наведите прицел на астероид
2. Зажмите `Ctrl`
3. От астероида отлетают **воксели ресурсов**

### Шаг 3: Соберите ресурсы

1. Подлетите к вокселям
2. Откройте люк (`O`)
3. Воксели автоматически затягиваются в корабль

**Ресурсы за воксель:**
- ⚙️ Металл: 10 ед.
- 💎 Кремний: 8 ед.
- ❄️ Лёд: 12 ед. (+5 воды при переработке)
- 🌟 Редкие: 3 ед.

## ☀️ Звезда: друг и враг

### Зарядка энергией

| Дистанция | Зона | Зарядка | Радиация |
|-----------|------|---------|----------|
| < 50 м | **СМЕРТЬ** | +100 ед/сек | +10%/сек |
| 50-100 м | Аура | +100 ед/сек | +5%/сек |
| 100-300 м | Средняя | +30 ед/сек | +2%/сек |
| 300-1000 м | Дальняя | +5 ед/сек | 0%/сек |

**Стратегия:**
- Подлетите близко для быстрой зарядки
- Но не слишком близко — радиация опасна!

### Опасности

**100% радиация = смерть за 30 секунд!**

Лечение:
- Естественное: медленно (минуты)
- Медотсек станции: быстро (10 секунд)

## 🏪 Станции

### Услуги

Нажмите `V` near станции:

- 💧 **Вода** — бесплатно (100%)
- ⚡ **Энергия** — бесплатно (100%)
- 🏥 **Медотсек** — лечение радиации (10 сек)
- 🚀 **Ракеты** — 10 редких ресурсов

### Строительство

1. Создайте станцию в конструкторе
2. Сохраните как `.blueprint.json`
3. Загрузите через меню станций
4. Разместите в космосе

**Важно:** Станции принадлежат вам — другие игроки не могут их удалить!

---

## 🎯 Выделение и наведение

### Клик мышью

1. **Наведите курсор** на объект (звезда, астероид, станция)
2. **Кликните ЛКМ** — объект выделен зелёным кольцом
3. Корабль **автоматически наводится** на объект

### Снятие выделения

- Клик ЛКМ в пустоте
- Или нажмите `ESC`

---

## ℹ️ Информация об объектах

### Клавиша `I`

Наведите мышь на объект и нажмите `I`:

**Звезда:**
- Дистанция, зона
- Зарядка энергией
- Радиация
- 🔮 Секретные события (артефакты, аномалии, сигналы)

**Астероид:**
- Тип (металл/кремний/лёд/редкий)
- Дистанция, координаты
- Ресурсы за воксель

**Станция:**
- Название, владелец
- Дистанция, координаты
- Доступные услуги

## 💡 Советы новичкам

### Первые минуты

1. **Не летите к звезде!** — опасно для новичков
2. **Добывайте лёд** — нужна вода для двигателей
3. **Соберите металл** — для спутников
4. **Постройте станцию** — база для расширения

### Экономия ресурсов

- **Тяга 50%** — достаточно для манёвров
- **Турбо только для перелётов**
- **Не открывайте люк** near астероидов (столкновения!)

### Безопасность

- **Следите за водой** — без неё двигатели отключатся
- **Следите за энергией** — без неё лазер не работает
- **Избегайте 100% радиации** — лечитесь на станциях

### Продвинутые

- **Используйте автонаведение** — клик на объекте
- **Комбинируйте с `I`** — полная информация
- **Копите редкие ресурсы** — нужны для ракет

## ⚠️ Опасности

### Столкновения

| Объект | Урон щитам | Эффект |
|--------|------------|--------|
| Астероид | -15% | Остановка + отскок |
| Воксель | -5% | -50% скорости |
| **Звезда** | **-100%** | **МГНОВЕННАЯ СМЕРТЬ** |

### Радиация

| Уровень | Эффект |
|---------|--------|
| 0-50% | Без эффектов |
| 50-80% | Предупреждение на HUD |
| 80-100% | Критическое предупреждение |
| **100%** | **Смерть за 30 секунд** |

**Лечение:**
- Медотсек станции (10 секунд)
- Естественное (очень медленно)

## 🔮 Секретные события

### Артефакты

- Скрыты в астероидах
- Звезда показывает "✳️ Артефакты: Обнаружены!"
- Нужно исследовать астероиды

### Аномалии

- Гравитационные искажения
- Радиационные выбросы
- Звезда показывает "🌌 Аномалии: Зафиксированы!"

### Сигналы

- SOS от других кораблей
- Неизвестные передатчики
- Звезда показывает "📡 Сигналы: Получен сигнал!"
