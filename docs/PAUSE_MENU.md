# 🚀 Пауза Меню - CosmoCraft

## Обзор

Пауза меню открывается по клавише **`T`** и показывает полную информацию о состоянии игрока, корабля и ресурсов.

---

## 📊 Информация в пауза меню

### 👤 ИГРОК
- **Имя** - имя текущего игрока
- **Станций** - количество построенных станций
- **Ранг** - текущий ранг игрока (Новичок, Опытный, Ветеран, и т.д.)

### 🚀 КОРАБЛЬ
- **Название** - имя корабля (Pioneer)
- **Щиты** - текущий уровень щитов в процентах
- **Энергия** - текущая энергия / максимальная ёмкость

### 📦 РЕСУРСЫ
Отображаются 4 типа ресурсов:
- **⚙️ Металл** - базовый строительный материал
- **💎 Кремний** - для электроники
- **❄️ Лёд** - источник воды
- **🌟 Редкие** - ценные ресурсы для продвинутых технологий

**Всего** - суммарное количество всех ресурсов

---

## 🎮 Кнопки меню

### 🚀 Выбор корабля
Открывает меню выбора/смены корабля.

**Текущий статус:** ⚠️ В разработке (доступен только корабль "Pioneer")

### 🏪 Выбор станции
Открывает меню выбора станции для размещения.

**Функционал:**
- Список личных станций (сохранённые чертежи)
- Список общих станций (доступные всем)
- Кнопка "Установить" для размещения выбранной станции

### ⏯️ ПРОДОЛЖИТЬ
Закрывает пауза меню и возвращает к игре.

---

## ⌨️ Управление

| Клавиша | Действие |
|---------|----------|
| `T` | Открыть/закрыть пауза меню |
| `ESC` | Закрыть меню |
| `ЛКМ` | Нажатие на кнопки меню |

---

## 🎯 Как использовать

1. Нажмите **`T`** для открытия пауза меню
2. Проверьте состояние корабля и ресурсов
3. При необходимости:
   - Нажмите **"Выбор корабля"** для смены корабля (в разработке)
   - Нажмите **"Выбор станции"** для размещения станции
4. Нажмите **"ПРОДОЛЖИТЬ"** или **`ESC`** для возврата к игре

---

## 💡 Советы

- Проверяйте ресурсы перед полётом к звезде
- Следите за уровнем щитов при столкновениях
- Используйте меню для быстрой навигации к станциям
- Энергия восстанавливается от звезды
