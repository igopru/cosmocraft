# 🚀 Управление кораблём - CosmoCraft

## Новая схема управления

### 📍 Основные принципы

- **Корабль летит туда, куда смотрит нос** - направление движения определяется ориентацией корабля
- **Тяга задаётся клавишами A/Z** - увеличивает/уменьшает скорость полёта
- **Стрелки вращают нос корабля** - выбирайте направление вращения

---

## 🎮 Клавиши управления

### ВРАЩЕНИЕ (выбор направления)

| Клавиша | Действие |
|---------|----------|
| `←` (стрелка влево) | Поворот носа **влево** (yaw) |
| `→` (стрелка вправо) | Поворот носа **вправо** (yaw) |
| `↑` (стрелка вверх) | Тангаж **вверх** (pitch) |
| `↓` (стрелка вниз) | Тангаж **вниз** (pitch) |

### МЕНЮ И СИСТЕМЫ

| Клавиша | Действие |
|---------|----------|
| `T` | **Пауза меню** - информация о пилоте, корабле, ресурсах + кнопки выбора корабля/станции |
| `I` | Информация об объекте |
| `B` | Станция/Строительное меню |
| `N` | Тактическая навигация |

---

## 🔐 Правила безопасности пилота

### Имя игрока
- **Длина:** от 3 до 20 символов
- **Разрешены:** буквы (русские/английские), цифры, пробелы, подчёркивания
- **Запрещены:** специальные символы `< > " ' ; -- /* */ \ / . * ? | & $ # @ ! % ^ ( ) [ ] { } , = + ` ~`

### Имя станции/корабля
- **Длина:** от 3 до 30 символов
- **Только:** латинские буквы, цифры, подчёркивания
- **Пример:** `MyStation_1`, `Pioneer_Base`, `Alpha_7`

### Защита данных
- Каждый игрок получает уникальный UUID-индекс
- Папки игроков изолированы: `~/players/{playerIndex}/`
- Имена обфусцируются через HMAC-SHA256
- БД MySQL хранит только индексные ID

---

## 💾 Хранение данных

### Игроки
- **БД MySQL:** информация, позиция, ресурсы
- **Файлы:** станции в `~/players/{playerIndex}/*.blueprint.json`

### Станции
- **Личные:** `~/players/{playerIndex}/`
- **Общие:** `~/stations/shared/`

### Ресурсы по умолчанию
- Металл: 1000
- Кремний: 500
- Лёд: 300
- Редкие: 100

### ДВИЖЕНИЕ (тяга)

| Клавиша | Действие |
|---------|----------|
| `A` | **Увеличить тягу** (+10%) |
| `Z` | **Уменьшить тягу** (-10%) |
| `Backspace` | **Сброс скорости** (тяга = 0) |

> Корабль автоматически летит в направлении, куда смотрит нос. Чем выше тяга, тем быстрее полёт.

## ⛏️ Добыча ресурсов

### Лазерная добыча

| Клавиша | Действие |
|---------|----------|
| `Ctrl` (левая/правая) | **Огонь из лазера** |

**Как это работает:**
1. Наведите лазер на астероид (прицел в центре экрана)
2. Зажмите `Ctrl` для выстрела
3. При попадании от астероида откалывается **воксельная крупинка** ресурса
4. Крупинка начинает летать вокруг астероида

**Типы ресурсов:**
- ⚙️ **Металл** (серый) - из металлических астероидов
- 💎 **Кремний** (синий) - из кремниевых астероидов
- ❄️ **Лёд** (голубой) - из ледяных астероидов
- 🌟 **Редкие** (оранжевый) - из редких астероидов

## 🚪 Грузовой отсек

### Люк

| Клавиша | Действие |
|---------|----------|
| `O` | **Открыть/закрыть грузовой люк** |

**Сбор ресурсов:**
1. Подлетите близко к частице ресурса
2. Откройте люк клавишей `O`
3. Частица автоматически затягивается в корабль
4. Ресурс добавляется в грузовой отсек

**Автоматический сбор:**
- При открытии люка все частицы в радиусе ~15 единиц автоматически собираются

## 🛰️ Спутники

### Развёртывание и отзыв

| Клавиша | Действие | Стоимость |
|---------|----------|-----------|
| `K` | **Развернуть спутник** | 50 металла |
| `H` | **Отозвать все спутники** | - |

**Спутники:**
- Летают вокруг корабля по орбите
- Визуализируются зелёными октаэдрами
- При отзыве возвращается 50% стоимости (25 металла за каждый)

## 🎯 Игровой процесс

### Типичная миссия по добыче:

1. **Поиск астероида**
   - Вращайте корабль стрелками
   - Ищите астероиды в космосе

2. **Сближение**
   - Наведите нос на астероид
   - Увеличьте тягу (`A`)
   - Подлетите близко (~50-100 единиц)

3. **Добыча**
   - Прицельтесь в астероид
   - Стреляйте лазером (`Ctrl`)
   - Наблюдайте, как отлетают частицы

4. **Сбор**
   - Подлетите к частицам
   - Откройте люк (`O`)
   - Ресурсы автоматически соберутся

5. **Развёртывание спутников** (опционально)
   - Нажмите `K` для развёртывания
   - Спутники будут летать вокруг
   - Используйте для разведки или связи

## 💡 Советы

- **Экономьте тягу** - держите её на минимуме при маневрировании
- **Сначала соберите металл** - он нужен для спутников
- **Используйте турбо** для быстрых перелётов
- **Закрывайте люк** при столкновениях - берегите ресурсы!
- **Спутники можно отозвать** если нужны ресурсы

## 🎨 Визуальные эффекты

### Лазер
- Красный луч из центра экрана
- Оранжевая сфера в точке попадания
- Анимация пульсации при попадании

### Частицы ресурсов
- Воксельные кубики 1.5×1.5×1.5
- Цвет зависит от типа ресурса
- Вращаются и летают по орбите вокруг астероида

### Спутники
- Зелёные октаэдры
- Летают по эллиптической орбите вокруг корабля
- Всегда ориентированы на корабль

---

## 🔧 Технические детали

### Физика полёта
- Направление задаётся вращением корабля (кватернионы)
- Скорость = (тяга / 100) × макс.скорость × модификаторы
- Движение строго по направлению носа

### Сбор ресурсов
- Дистанция сбора: 15 единиц
- Автоматический сбор при открытии люка
- Мгновенное добавление в HUD

### Столкновения
- При ударе -10% щитов
- Сброс скорости до 0
- 1 секунда неуязвимости
- При щитах = 0 - респавн
