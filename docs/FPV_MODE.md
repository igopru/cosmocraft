# Полёт и Магазин Станций - CosmoCraft

## Обзор

**Полёт на корабле - основной режим игры**. Вы управляете космическим кораблём с видом от первого лица. Модель корабля скрыта для лучшего обзора, по краям экрана видны ориентиры орудий.

## Быстрый старт

1. **Игра начинается сразу в режиме полёта**
2. **Кликните по экрану** для захвата мыши
3. **W** - полёт вперёд
4. **Мышь** - поворот корабля
5. **V** - открыть магазин станции (если рядом есть станция)
6. **C** - переключение камеры (полёт ↔ осмотр)

## Управление

### Полёт (камера привязана к кораблю)

| Клавиша | Действие |
|---------|----------|
| `W` | **Вперёд** по направлению взгляда |
| `S` | **Торможение** (если движетесь) / **Назад** (если стоите) |
| `A` | **Поворот носа влево** (yaw) |
| `D` | **Поворот носа вправо** (yaw) |
| `Q` | **Тангаж вверх** (pitch - нос вверх) |
| `E` | **Тангаж вниз** (pitch - нос вниз) |
| **Мышь** | **Поворот корабля** (после клика по экрану) |
| **ЛКМ** | Фокусировка на цели (автоповорот) |
| **ПКМ** | Стабилизация вращения |
| **` (ё)** | Посадка на ближайшую станцию |
| `F` | Сменить вид корабля (спрайт/3D) |
| `C` | **Переключение камеры** (полёт ↔ осмотр) |
| `V` | Магазин станции |

### Стрелки (дублирование)

| Клавиша | Действие |
|---------|----------|
| `↑` | Вперёд |
| `↓` | Тормоз / Назад |
| `←` | Поворот влево |
| `→` | Поворот вправо |

### Осмотр (свободная камера)

| Клавиша | Действие |
|---------|----------|
| `C` | Вернуться в режим полёта |
| **Мышь** | Вращение камеры (OrbitControls) |
| **Колесо** | Приближение/отдаление |

## Важные моменты

### 🖱️ Захват мыши
- **Кликните по экрану** для захвата мыши
- После захвата мышь управляет поворотом корабля
- Для освобождения мыши нажмите `ESC`

### 🚀 Торможение
- **S работает умно**: 
  - Если летите вперёд → **тормозит** (быстрее чем разгон)
  - Если остановились → **движение назад** (медленнее)

### 🎯 Поворот корабля
- **Мышь** - основной способ поворота (после клика)
- **A/D** - поворот носа влево/вправо
- **Q/E** - тангаж (нос вверх/вниз)

## Режимы Камеры

### 🚀 Полёт (Follow Camera)
- Камера привязана к кораблю
- Модель корабля **скрыта** (FPV режим)
- По краям видны **ориентиры орудий**
- Управление кораблём активно
- OrbitControls отключён
- **Основной режим игры**

### 📷 Осмотр (Orbit Camera)
- Свободная орбитальная камера
- Можно вращать вокруг сцены
- Корабль продолжает висеть в пространстве
- Для осмотра красот космоса и станций
- Нажмите **C** для возврата в полёт

3. **📦 Modules** (Модули)
   - Солнечная панель - 200 cr
   - Аккумулятор - 150 cr

   - Турель - 800 cr

4. **🔧 Services** (Услуги)
   - Ремонт - 100 cr
   - Заправка - 50 cr
   - Станковка - 25 cr
   - Информация - 200 cr

## Посадка на Станцию

1. Подлетите к станции на расстояние < 500 единиц
2. Нажмите **` (ё)** - клавиша слева от 1
3. Корабль автоматически приблизится к станции
4. Посадка выполнится на дистанции 50 единиц

## Настройки

Конфигурация корабля в конструкторе:

```typescript
this.spaceship = new Spaceship(this.scene, this.camera, {
    maxSpeed: 800,           // Максимальная скорость
    acceleration: 200,       // Ускорение (вперёд)
    rotationSpeed: 3.0,      // Скорость поворота
    damping: 0.95,           // Затухание скорости
    mouseSensitivity: 0.003, // Чувствительность мыши
    wasdArrowsDuplicate: true, // Дублирование WASD на стрелки
    hideShip: true,          // Скрыть модель корабля в FPV
    showGunHUD: true         // Показать ориентиры орудий
});
```

## Привязка Спрайтов

Для 2D спрайта вместо 3D модели:

```typescript
// При создании
this.spaceship = new Spaceship(this.scene, this.camera, {
    spritePath: '/path/to/sprite.png',
    hideShip: false  // Показать спрайт
});

// Или динамически
game.setSpaceshipSprite('/path/to/sprite.png');
```

## Тестирование

1. Запустите: `npm run dev`
2. Войдите в игру
3. **Кликните по экрану** для захвата мыши
4. **W** - полёт вперёд
5. **Мышь** - поворот корабля
6. Разместите станцию через меню
7. Подлетите к станции (< 500 единиц)
8. Нажмите **V** - магазин откроется
9. Нажмите **C** - переключение на свободную камеру
10. Нажмите **C** снова - возврат в корабль
11. Нажмите **` (ё)** - посадка на станцию

## Примечания

- **Полёт - основной режим** с начала игры
- **Клик по экрану** захватывает мышь для управления
- **Модель корабля скрыта** для лучшего обзора
- **Ориентиры орудий** по краям помогают чувствовать габариты
- **S сначала тормозит**, потом двигает назад
- Камера **C** переключается только в полёте
- Магазин **V** работает только рядом со станцией
- Посадка **`** требует станцию в радиусе 500 единиц
