# 🛡️ Админ-панель

## Обзор

Веб-интерфейс для управления игроками, заданиями, настройками сервера и мониторинга безопасности.

**URL:** `https://cosmocraft.rupru.ru/admin` (или `http://localhost:8001/admin`)

**Версия:** 0.5.1

---

## 🔐 Вход

| Поле | Значение |
|------|----------|
| Логин | `admin` |
| Пароль | из `.env` (`ADMIN_PASSWORD`) |

После входа JWT-токен сохраняется в `localStorage` (срок 8 часов).

---

## 📑 Вкладки

### 1. 🏠 Обзор

Карточки статистики сервера (автообновление каждые 30 секунд):

| Метрика | Источник |
|---------|----------|
| Всего игроков | `admin_server_stats.total_players` |
| Онлайн | `admin_server_stats.online_players` |
| Активные сессии | `admin_server_stats.active_sessions` |
| Входы за 24ч | `admin_server_stats.logins_24h` |

Таблица активных игроков (VIEW `admin_active_players`).

### 2. 👥 Игроки

Таблица всех зарегистрированных игроков:

| Колонка | Источник |
|---------|----------|
| # | Порядковый номер |
| Имя игрока | `players.username` + ID (первые 8 символов) |
| Email | `pilot_credentials.email` |
| Последний вход | `players.last_login` |
| Статус | Онлайн / Офлайн / 🔒 Заблокирован |
| Действия | Заблокировать / Разблокировать / Удалить |

**Действия:**
- **Заблокировать** — устанавливает `is_account_locked = TRUE`, удаляет все сессии
- **Разблокировать** — сбрасывает блокировку и счётчик неудачных входов
- **Удалить** — удаляет игрока (CASCADE для связанных данных)

### 3. 🎯 Задания

#### Статистика
Общее количество заданий, распределение по категориям и сложности.

#### CRUD таблица
| Колонка | Описание |
|---------|----------|
| Название | Кликабельно для редактирования |
| Категория | history / science / exploration |
| Тип | quiz / flight / search / visit |
| Сложность | easy / medium / hard |
| Награды | XP, топливо, металл, кремний, лёд, редкие |
| Действия | Редактировать / Удалить |

#### Создание задания
Модальное окно с полями:
- Название, описание, категория, тип, сложность
- Для викторины: вопрос, 4 варианта ответа, индекс правильного ответа
- Награды: XP, топливо, металл, кремний, лёд, редкие
- Флаги: активно, повторяемое

#### Ранги
Таблица 8 рангов пилотов с требуемым XP и описанием.

### 4. ⚙️ Настройки

5 категорий настроек из `server_settings`:

| Категория | Параметры |
|-----------|-----------|
| **🌐 Общие** | Имя сервера, описание, версия, режим обслуживания, макс. игроков |
| **Auth** | Регистрация, email, 2FA, мин. длина пароля |
| **Game** | Seed мира, сложность, PvP, множитель ресурсов |
| **Email** | SMTP сервер, порт, от, имя |
| **Security** | IP whitelist, rate limit, макс. попыток, блокировка |

Toggle-переключатели для boolean, текстовые поля для остальных.

### 5. 🛡️ Безопасность

#### Статистика за 24ч (8 карточек)
| Метрика | API |
|---------|-----|
| Уникальные IP | `/api/admin/security/stats` |
| WS запросы (8080) | `ws_requests_24h` |
| HTTP запросы (8001) | `http_requests_24h` |
| Ошибки (4xx/5xx) | `error_requests_24h` |
| Неавторизованные (401) | `unauthorized_24h` |
| Запрещённые (403) | `forbidden_24h` |
| Неудачные входы | `failed_logins_24h` |
| Действия админов | `admin_actions_24h` |

#### Подозрительная активность
Таблица IP/email с 3+ неудачными попытками входа (VIEW `admin_suspicious_activity`).

#### Запросы на порты
Таблица последних запросов за 24ч: время, IP, порт, метод, путь, статус, время ответа.

#### Топ IP с ошибками
Рейтинг IP по количеству 401/403/5xx ошибок.

### 6. 📋 Журнал

#### Действия администраторов
Таблица из `admin_actions_log`:
- Время, администратор, действие, цель, детали

#### Журнал изменений
Таблица из `admin_audit_log`:
- Время, администратор, действие, ресурс, старое значение → новое значение

## 🐛 Известные проблемы и решения

### `ER_WRONG_ARGUMENTS` в mysql2
**Симптом:** `Incorrect arguments to mysqld_stmt_execute` при запросе `/api/admin/players`

**Причина:** `parseInt(req.query.param)` возвращает `NaN` для пустых значений, что mysql2 не принимает в prepared statements.

**Решение:**
- `safeInt(value, def)` с `Number.isFinite()` проверкой
- `LIMIT ? OFFSET ?` заменено на `LIMIT ${lim} OFFSET ${off}` с `Number()` валидацией
- `DatabaseManager.execute(query)` теперь передаёт `[]` вместо `undefined`

### Краш сервера на HTTP запросах
**Симптом:** Сервер падает при первом HTTP запросе к админке

**Причина:** Обёртка `res.end` в middleware логирования ломала Express 5

**Решение:** Middleware логирования запросов на порты временно убран
