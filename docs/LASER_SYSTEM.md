# 🔫 Лазерная система добычи ресурсов

## Обзор

Система лазерной добычи позволяет получать ресурсы из астероидов путём выстрела из лазера. При попадании от астероида откалываются **воксельные крупинки** ресурсов, которые можно собрать.

---

## 🎮 Управление

| Клавиша | Действие |
|---------|----------|
| `Ctrl` (левая/правая) | **Огонь из лазера** |
| `O` | Открыть/закрыть грузовой люк (для сбора ресурсов) |

---

## 🔬 Как это работает

### 1. Стрельба из лазера

При нажатии `Ctrl`:
- Запускаются **два лазерных луча** из нижних углов корабля
- Лучи сходятся в центре экрана (в точке прицеливания)
- Длительность луча: **150 мс**
- Перезарядка: **0.15 секунды**

**Визуализация:**
- Левый лазер: из точки `(-3, -1, 0)` в локальных координатах
- Правый лазер: из точки `(3, -1, 0)` в локальных координатах
- Оба луча направлены в точку пересечения с объектом

### 2. Попадание в астероид

При попадании в астероид:
1. В точке попадания появляется **оранжевая сфера** (пульсирует 0.3 сек)
2. От астероида откалываются **воксели ресурсов**
3. Воксели разлетаются в случайных направлениях

**Количество вокселей:**
| Тип астероида | Вокселей |
|---------------|----------|
| Металлический | 1 |
| Кремниевый | 2 |
| Ледяной | 2 |
| Редкий | 3 |

### 3. Типы ресурсов

| Ресурс | Цвет | Из астероида |
|--------|------|--------------|
| ⚙️ Металл | Серый `(0x888888)` | Металлический |
| 💎 Кремний | Синий `(0x66aaff)` | Кремниевый |
| ❄️ Лёд | Голубой `(0xaaddff)` | Ледяной |
| 🌟 Редкие | Оранжевый `(0xffaa44)` | Редкий |

## 📦 Сбор ресурсов

### Автоматический сбор

При **открытом грузовом люке** (`O`):
- Все воксели в радиусе **15 единиц** автоматически затягиваются в корабль
- Ресурсы добавляются в грузовой отсек

**Количество ресурсов за воксель:**
- Металл: **+10**
- Кремний: **+8**
- Лёд: **+12**
- Редкие: **+3**

### Ручной сбор

1. Подлетите близко к вокселю (< 15 единиц)
2. Откройте люк (`O`)
3. Воксель автоматически соберётся

---

## 💥 Столкновения

### Столкновение с вокселем

Если воксель касается корабля (**дистанция < 5**):
- **-5% щитов**
- **-50% скорости** корабля
- Воксель уничтожается

### Столкновение с астероидом

Проверка каждые **1 секунды** (raycast вперёд на 15 единиц):

Если дистанция до астероида **< 10 единиц**:
- **-15% щитов**
- **Полная остановка** (скорость = 0)
- **Отскок** корабля назад
- **1 секунда неуязвимости**

Если щиты = 0 → **Респавн**

## 🏆 Система престижа

Энергопотребление лазера зависит от уровня престижа мира:

| Престиж | Энергия на выстрел | Вокселей за выстрел |
|---------|-------------------|---------------------|
| 1 | 1 | 1-3 (норма) |
| 2 | 2 | 1-3 |
| 3 | 3 | 1-2 (урезано) |
| 4+ | 5+ | 1 (минимум) |

**На высоких уровнях престижа:**
- Требуется больше энергии на выстрел
- Меньше вокселей за одно попадание
- Нужно больше выстрелов для добычи

## 🔄 Цикл обновления

### Выстрел (fireLaser)

```
1. Проверка cooldown (0.15 сек)
2. Raycast из камеры в центр экрана
3. Если попадание в астероид:
   - Сохранить hitPoint и hitAsteroid
4. Обновить левый лазер (от левого угла до hitPoint)
5. Обновить правый лазер (от правого угла до hitPoint)
6. Показать сферу попадания
7. Создать воксели (createResourceVoxels)
8. Скрыть лучи через 150 мс
```

### Обновление вокселей (updateResourceVoxels)

```
Для каждого вокселя:
1. Обновить позицию (velocity * deltaTime)
2. Обновить вращение (rotationSpeed * deltaTime)
3. Если люк открыт:
   - Проверка дистанции до корабля
   - Если < 15: собрать (collectVoxel)
4. Проверка столкновения с кораблём:
   - Если < 5: handleVoxelCollision
```

### Проверка столкновений (checkAsteroidCollisions)

```
1. Raycast вперёд по направлению носа (15 единиц)
2. Фильтр: только астероиды (userData.type)
3. Если попадание < 10 единиц:
   - handleAsteroidCollision
   - -15% щитов
   - Остановка + отскок
   - 1 сек неуязвимости
```

## 📝 Советы

1. **Экономь энергию** — не стреляй без нужды на высоких престижах
2. **Собирай сразу** — открывай люк после серии выстрелов
3. **Избегай столкновений** — воксели наносят урон щитам
4. **Целься в центр** — воксели вылетают из точки попадания
5. **Используй инерцию** — при столкновении корабль отскакивает
