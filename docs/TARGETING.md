# 🎯 Система выделения и автонаведения

## Обзор

Игрок может выделять объекты космоса кликом мыши, после чего корабль автоматически наводится на цель.

---

## 🎮 Управление

| Действие | Управление |
|----------|------------|
| **Выделить объект** | Клик **ЛКМ** по объекту |
| **Снять выделение** | Клик **ЛКМ** в пустоте |
| **Информация** | Клавиша `I` |
| **Отмена автонаведения** | Снять выделение |

---

## 🎯 Как работает

### 1. Выделение объекта

**Шаги:**
1. Наведите курсор мыши на объект (звезда, астероид, станция)
2. Кликните **левой кнопкой мыши**
3. Вокруг объекта появится **зелёное кольцо** (маркер)

**Результат:**
- Объект выделен
- Включается **автонаведение**
- Корабль автоматически поворачивается носом к цели

### 2. Автонаведение

**Автоматическое:**
- Корабль плавно поворачивается к цели
- Скорость поворота: 3.0 рад/сек
- Точность: 0.05 рад (~3°)

**Визуально:**
- Зелёное кольцо следует за объектом
- Кольцо всегда повёрнуто к камере
- При наведении кольцо исчезает (цель достигнута)

### 3. Снятие выделения

**Способы:**
- Клик **ЛКМ** в пустом пространстве
- Нажатие `I` (информация) не снимает выделение
- Закрытие игры

## ⚙️ Математика автонаведения

### Вычисление направления

```typescript
// Вектор к цели
const toTarget = targetPos.clone()
    .subVectors(targetPos, shipPosition);
toTarget.normalize();

// Текущее направление корабля
const forward = shipForward.clone().normalize();

// Угол между направлениями
const angle = forward.angleTo(toTarget);
```

### Поворот корабля

```typescript
if (angle > 0.05) {  // Если угол больше 3°
    const rotationSpeed = 3.0 * deltaTime;
    
    // Ось вращения (перпендикуляр к обоим векторам)
    const axis = new THREE.Vector3()
        .crossVectors(forward, toTarget);
    
    // Кватернион поворота
    const q = new THREE.Quaternion();
    q.setFromAxisAngle(axis, Math.min(angle, rotationSpeed));
    ship.quaternion.premultiply(q);
}
```

## 🎯 Приоритеты выделения

**Объекты для выделения:**
1. **Звезда** (`name === 'star'`)
2. **Астероиды** (`userData.type`)
3. **Станции** (`userData.isStation`)

**Приоритет:**
- Если мышь на объекте → выделение объекта
- Если мышь в пустоте → снятие выделения

---

## 💡 Советы

### Для новичков

1. **Кликните на астероид** — корабль сам повернётся
2. **Зелёное кольцо** — цель захвачена
3. **Клик в пустоте** — отмена автонаведения

### Для опытных

1. Используйте **автонаведение** для быстрого разворота
2. **Комбинируйте** с информацией (`I`) для анализа
3. **Снимайте выделение** после манёвра
