# ℹ️ Система информации об объектах

## Обзор

Игрок может получить подробную информацию об объектах космоса (звезда, астероиды, станции) с помощью клавиши **`I`**.

---

## 🎮 Управление

| Действие | Клавиша |
|----------|---------|
| Информация об объекте | `I` или `i` |
| Закрытие окна | `ESC` или кнопка "Закрыть" |

---

## 🔍 Как использовать

### Способ 1: Наведение мышью (рекомендуется)

1. **Наведите курсор мыши** на объект (звезда, астероид, станция)
2. Нажмите **`I`**
3. Получите **полную информацию** об объекте

### Способ 2: Ближайший объект

1. Если мышь **не на объекте**, покажется информация о **ближайшем объекте**
2. Используйте как подсказку для поиска

## 🔮 Секретные события (Сценарии)

### Артефакты

**Как узнать:**
- Звезда показывает "✳️ Артефакты: Обнаружены!"
- Игрок должен исследовать астероиды рядом
- Артефакты скрыты в обычных астероидах

**Нахождение:**
1. Получить информацию от звезды
2. Лететь в указанную зону
3. Сканировать астероиды (будущая механика)
4. Найти артефакт

### Аномалии

**Типы:**
- Гравитационные искажения
- Радиационные выбросы
- Пространственные разломы

**Обнаружение:**
- Звезда показывает "🌌 Аномалии: Зафиксированы!"
- Игрок должен найти источник

### Сигналы

**Типы:**
- SOS от других кораблей
- Неизвестные передатчики
- Зашифрованные сообщения

**Механика:**
- Звезда показывает "📡 Сигналы: Получен сигнал!"
- Игрок должен запеленговать источник

## 💡 Подсказки

### Для новичков

1. **Наведите мышь** на объект для точной информации
2. Если не уверены — нажмите `I`, покажете ближайший объект
3. **Звезда** — главный источник информации о секретных событиях
4. **ESC** закроет любое информационное окно

### Для опытных

1. Проверяйте **зону звезды** перед сближением
2. Следите за **секретными событиями** — это квесты!
3. **Координаты** помогают отмечать интересные места
4. **Дистанция** важна для безопасности

## 🔧 Техническая реализация

### Raycasting от мыши

```typescript
// Нормализованные координаты мыши
mousePosition.x = (clientX / width) * 2 - 1;
mousePosition.y = -(clientY / height) * 2 + 1;

// Raycasting
raycaster.setFromCamera(mousePosition, camera);
intersects = raycaster.intersectObjects(scene.children);
```

### Определение объекта

```typescript
// Ищем объект с userData
let parent = intersects[0].object;
while (parent && !parent.userData?.type) {
    parent = parent.parent;
}

// Типы объектов
- obj.name === 'star' → Звезда
- obj.userData?.type → Астероид
- obj.userData?.isStation → Станция
```
