# Управление кораблём в стиле X-Beyond the Frontier

## Дата добавления
2026-03-08

## Обзор

Добавлено полноценное управление кораблём в стиле классической космической симуляции **X-Beyond the Frontier**. Управление реализовано через новый класс `ShipController`.

## Схема управления

### 🎮 Движение и навигация

| Клавиша | Действие |
|---------|----------|
| `↑` (Стрелка вверх) | Движение вперёд |
| `↓` (Стрелка вниз) | Движение назад |
| `←` (Стрелка влево) | Движение влево (стрейф) |
| `→` (Стрелка вправо) | Движение вправо (стрейф) |
| `PageUp` | Подъём вверх по оси Y |
| `PageDown` | Спуск вниз по оси Y |
| `Q` | Вращение влево (крен) |
| `W` | Вращение вправо (крен) |

### ⚡ Скорость и ускорение

| Клавиша | Действие |
|---------|----------|
| `A` | Увеличить тягу (+10%) |
| `Z` | Уменьшить тягу (-10%) |
| `Backspace` | Сбросить скорость в ноль |
| `Tab` / `B` | Турбо-режим (x2 скорости) |
| `J` | S.E.T.A (сжатое время, x5 скорости) |
| `Shift+J` | S.E.T.A Boost Extension (x10 скорости) |

### 🔫 Вооружение

| Клавиша | Действие |
|---------|----------|
| `Ctrl` (левый/правый) | Огонь из лазера |
| `L` | Запуск ракеты |
| `M` | Выбрать следующую ракету |

### 📊 Информационные системы

| Клавиша | Действие |
|---------|----------|
| `N` | Tactical Navigation System (тактическая карта) |
| `I` | Информация об объекте в прицеле |
| `P` | Информация о пилоте (статус, статистика) |
| `S` | Информация о корабле (щит, вооружение, груз) |

### 🚀 Специальные системы

| Клавиша | Действие |
|---------|----------|
| `O` | Открыть/закрыть грузовой люк |
| `D` | Стыковочный компьютер (автостыковка) |
| `U` | Motion Analysis Relay (автопилот) |
| `F` | Сброс груза |

## HUD корабля

В правом нижнем углу экрана отображается панель статуса корабля:

```
┌─────────────────────────┐
│ 🚀 Корабль              │
├─────────────────────────┤
│ Скорость: 0 м/с         │
│ Тяга: 0%                │
│ Макс: 100 м/с           │
│                         │
│ ⚡ Турбо | ⏱️ S.E.T.A   │
│ 🚪 Люк   | 🔥 Лазер     │
│                         │
│ Ракета: None            │
└─────────────────────────┘
```

### Индикаторы

- **Скорость** - текущая скорость в м/с
- **Тяга** - процент тяги двигателей (0-100%)
- **Макс** - максимальная скорость с учётом модификаторов
- **Турбо** - зелёный, когда активен турбо-режим
- **S.E.T.A** - зелёный, когда активно сжатое времени
- **Люк** - зелёный, когда грузовой люк открыт
- **Лазер** - красный, когда идёт стрельба
- **Ракета** - тип выбранной ракеты

## Архитектура

### Класс ShipController

**Расположение:** `src/client/ShipController.ts`

**Основные свойства:**
- `speed: number` - текущая скорость
- `maxSpeed: number` - базовая максимальная скорость
- `throttle: number` - процент тяги (0-100)
- `turboMode: boolean` - турбо-режим
- `setaMode: boolean` - режим сжатого времени
- `setaBoost: boolean` - ускоренный режим S.E.T.A
- `cargoBayOpen: boolean` - статус грузового люка
- `laserActive: boolean` - активность лазера
- `currentMissile: string` - выбранная ракета

**Основные методы:**
- `update(deltaTime)` - обновление физики движения
- `setOnStatusUpdate(callback)` - установка callback для HUD
- `getStatus()` - получение текущего статуса
- `dispose()` - очистка обработчиков событий

### Интеграция с игрой

```typescript
// В CosmoCraftGame constructor
this.shipController = new ShipController(this.camera, this.scene);

// Callback для обновления HUD
this.shipController.setOnStatusUpdate((status) => {
    this.hud.setShipStatus(status);
});

// В animate()
this.shipController.update(delta);
```

## Физика движения

### Обработка зажатых клавиш

```typescript
// Движение вперёд/назад
if (keysPressed.has('ArrowUp')) {
    camera.position.add(forward.multiplyScalar(moveSpeed));
}
if (keysPressed.has('ArrowDown')) {
    camera.position.add(forward.multiplyScalar(-moveSpeed));
}

// Движение влево/вправо (стрейф)
if (keysPressed.has('ArrowLeft')) {
    camera.position.add(right.multiplyScalar(-moveSpeed));
}
if (keysPressed.has('ArrowRight')) {
    camera.position.add(right.multiplyScalar(moveSpeed));
}

// Движение вверх/вниз по Y
if (keysPressed.has('PageUp')) {
    camera.position.y += moveSpeed;
}
if (keysPressed.has('PageDown')) {
    camera.position.y -= moveSpeed;
}
```

### Расчёт скорости

```typescript
updateSpeed() {
    let baseMaxSpeed = this.maxSpeed;
    
    if (this.turboMode) baseMaxSpeed *= 2;      // x2
    if (this.setaMode) baseMaxSpeed *= 5;       // x5
    if (this.setaBoost) baseMaxSpeed *= 10;     // x10
    
    this.speed = (this.throttle / 100) * baseMaxSpeed;
}
```

## Обновление от 2026-03-08

### 🖱️ Управление мышью (ИСПРАВЛЕНО)

**Правильный POV (вид от первого лица):**
- Камера смотрит из центра корабля вперёд
- Движение мыши вращает камеру (и нос корабля)
- Мышь влево/вправо = поворот камеры по горизонтали (yaw)
- Мышь вверх/вниз = поворот камеры по вертикали (pitch)
- Вертикальный угол ограничен (не перевернётся)

**Технические детали:**
```typescript
// Вращение камеры (Euler углы)
cameraYaw   // Вокруг Y (влево/вправо)
cameraPitch // Вокруг X (вверх/вниз)
cameraRoll  // Крен вокруг Z

// Порядок вращения YXZ для FPS управления
camera.rotation.order = 'YXZ'

// Чувствительность мыши
mouseSensitivity = 0.002
```

### 🔥 Лазерная визуализация

Добавлены **визуальные эффекты лазера**:
- Красный луч из центра экрана
- Полупрозрачная сфера в точке попадания
- Пульсация сферы (увеличивается и исчезает)
- Длительность эффекта: 150мс

**Алгоритм работы лазера:**
```
1. Игрок нажимает Ctrl
2. Пускается луч (Raycaster) из центра камеры
3. Находится точка пересечения с объектом
4. Показывается красный луч до точки попадания
5. В точке попадания создаётся полупрозрачная сфера
6. Сфера пульсирует (увеличивается в 3 раза)
7. Через 150мс эффекты скрываются
```

### 🎮 Исправленное управление

**До исправления:**
- ❌ Камера смотрела на звезду (в центр сцены)
- ❌ Поворот мыши не работал правильно
- ❌ Движение вперёд было относительно сцены, не камеры

**После исправления:**
- ✅ Камера смотрит вперёд (POV из корабля)
- ✅ Мышь вращает камеру (и нос корабля)
- ✅ Движение вперёд по направлению взгляда камеры
- ✅ OrbitControls отключён для POV режима

## Совместимость с другими системами

### Станции
- Размещение станций через меню не конфликтует с управлением
- Режим размещения использует отдельные обработчики

### Конструктор
- Переход в конструктор (`/designer.html`) приостанавливает управление
- Возврат в игру восстанавливает управление

### HUD
- Панель статуса корабля не перекрывает основную информацию
- Координаты, сектор, ресурсы отображаются слева
- Статус корабля отображается справа внизу
