# Исправление кнопки "В игру" в дизайнере

## Проблема
При нажатии на кнопку "🚀 В игру" в дизайнере (`/public/designer.html`) происходила ошибка, и возврат в основную игру не выполнялся.

## Причина
1. Сервер пытался сохранить файл чертежа в папку `/station`, которая не существовала
2. API endpoint `/api/stations` (POST) возвращал ошибку при записи файла в несуществующую директорию
3. Перенаправление на `/index.html` не выполнялось из-за ошибки сохранения

## Решение

### 1. Создана папка для чертежей
```bash
mkdir -p /home/father/project/cosmocraft/station
```

### 2. Добавлено автоматическое создание папки в коде сервера
Файл: `src/server/GameServer.ts`

```typescript
// Создаем папку для чертежей, если она не существует
if (!fs.existsSync(stationPath)) {
  fs.mkdirSync(stationPath, { recursive: true });
  console.log(`📁 Папка для чертежей создана: ${stationPath}`);
}
```

### 3. Пересобран проект
```bash
npm run build:server
npm run build:client
```

## Проверка работы

1. Запустите сервер: `npm start`
2. Откройте в браузере: `http://localhost:8001/designer.html`
3. Постройте любую конструкцию из вокселей
4. Нажмите кнопку "🚀 В игру"
5. Введите название модели (например, `MyStation`)
6. После успешного сохранения произойдёт автоматический переход в игру: `http://localhost:8001/index.html`

## Формат файлов чертежей

Файлы сохраняются в папке `/station` в формате JSON:

```
{name}.blueprint.json
```

Пример: `MyStation.blueprint.json`

## API Endpoints

| Метод | Endpoint | Описание |
|-------|----------|----------|
| GET | `/api/stations` | Список всех моделей |
| GET | `/api/stations/:name` | Получить данные модели |
| POST | `/api/stations` | Сохранить новую модель |
| PUT | `/api/stations/:name` | Обновить существующую модель |
| DELETE | `/api/stations/:name` | Удалить модель |

## Примечание по запуску

Если возникает ошибка `EADDRINUSE: address already in use :::8080`, освободите порты:

```bash
# Освободить порты 8080 и 8001
lsof -ti:8080,8001 | xargs kill -9

# Или найти процесс вручную
lsof -i :8080
kill -9 <PID>
```

После этого запустите сервер:
```bash
npm run dev  # Режим разработки
# или
npm start    # Продакшн режим
```
