# Режим размещения станций с курсором-призраком

## Дата обновления
2026-03-08

## Описание функционала

Теперь при выборе станции из списка или загрузке новой модели появляется **режим интерактивного размещения**:

1. **Полупрозрачный призрак станции** следует за курсором мыши
2. **Автоматическое выравнивание** по сетке (шаг 8 единиц)
3. **Клик левой кнопкой** для размещения
4. **ESC** для отмены размещения

## Как использовать

### Размещение станции из списка

1. Нажмите кнопку **"🚀 Станции"** в нижнем меню
2. Найдите нужную станцию в списке
3. Нажмите кнопку **"Установить"**
4. Меню закроется, появится полупрозрачный призрак станции
5. Перемещайте мышь для выбора позиции
6. Кликните **ЛКМ** для размещения
7. Или нажмите **ESC** для отмены

### Размещение загруженной станции

1. Нажмите кнопку **"📥 Добавить"** в нижнем меню
2. Выберите JSON файл станции
3. Введите название
4. После успешной загрузки автоматически включится режим размещения
5. Разместите станцию кликом мыши

## Управление в режиме размещения

| Действие | Клавиша/Кнопка |
|----------|----------------|
| Перемещение призрака | Движение мыши |
| Разместить станцию | Левый клик (ЛКМ) |
| Отменить размещение | ESC |
| Игнорирование UI | Клик по меню не размещает |

## Технические детали

### Класс StationManager

**Новые свойства:**
- `placementMode: boolean` - активен ли режим размещения
- `ghostStation: THREE.Group | null` - группа призрака станции
- `currentBlueprint: StationBlueprint | null` - текущий чертёж
- `raycaster: THREE.Raycaster` - для определения пересечений
- `mouse: THREE.Vector2` - нормализованные координаты мыши

**Новые методы:**
- `enablePlacementMode(filename, onComplete)` - включение режима
- `createGhostStation(blueprint)` - создание призрака
- `onMouseMove(event)` - обработка движения мыши
- `onClick(event)` - обработка клика
- `onKeyDown(event)` - обработка клавиш
- `placeGhostStation()` - размещение станции
- `cancelPlacement()` - отмена размещения
- `disablePlacementMode()` - выключение режима
- `calculateCenter(blueprint)` - вычисление центра станции

### Алгоритм работы

```
1. Пользователь нажимает "Установить" в меню станций
2. Загружается JSON файл чертежа с сервера
3. Создаётся полупрозрачная копия станции (призрак)
4. Включается режим размещения (placementMode = true)
5. Добавляются обработчики: mousemove, click, keydown
6. При движении мыши:
   - Пускается луч (Raycaster) из камеры
   - Находится пересечение с объектами сцены
   - Призрак позиционируется в точке пересечения
   - Координаты округляются до сетки (8 единиц)
7. При клике ЛКМ:
   - Создаётся финальная копия призрака
   - Убирается прозрачность
   - Станция добавляется на сцену
   - Режим размещения отключается
8. При нажатии ESC:
   - Режим размещения отключается
   - Призрак удаляется
   - Станция не размещается
```

### Вычисление позиции

```typescript
// Нормализованные координаты мыши (-1 до 1)
mouse.x = (clientX / width) * 2 - 1
mouse.y = -(clientY / height) * 2 + 1

// Луч из камеры через точку мыши
raycaster.setFromCamera(mouse, camera)

// Пересечение с объектами
intersects = raycaster.intersectObjects(scene.children)

// Округление до сетки
gridX = Math.round(point.x / 8) * 8
gridY = Math.round(point.y / 8) * 8
gridZ = Math.round(point.z / 8) * 8
```

## Визуальные эффекты

### Призрак станции
- **Прозрачность:** 50% (opacity: 0.5)
- **Цвет:** Соответствует типам вокселей
- **Центрирование:** Позиция по центру модели

### Финальная станция
- **Прозрачность:** 100% (opacity: 1)
- **Цвет:** Соответствует типам вокселей
- **Позиция:** Где был призрак при клике

## Примеры использования в коде

### Включение режима размещения вручную

```typescript
// Из любого места в коде игры
const stationManager = game.getStationManager();

await stationManager.enablePlacementMode(
    'MyStation.blueprint.json',
    (success: boolean) => {
        if (success) {
            console.log('✅ Станция размещена');
        } else {
            console.log('❌ Размещение отменено');
        }
    }
);
```

### Проверка активного режима

```typescript
if (stationManager.isPlacementModeActive()) {
    console.log('Режим размещения активен');
    // Например, отключить управление камерой
}
```

## Совместимость

### Старый метод placeStation

Метод `placeStation(filename, position)` сохранён для обратной совместимости. Он размещает станцию сразу в указанную позицию без режима призрака.

```typescript
// Старый способ (работает)
const position = new THREE.Vector3(10, 10, 10);
await stationManager.placeStation('Station.json', position);

// Новый способ (рекомендуется)
await stationManager.enablePlacementMode('Station.json', callback);
```

## Планы развития

1. **Вращение станции** - клавиши R/Q для поворота
2. **Точный режим** - отключение привязки к сетке
3. **Предпросмотр высоты** - индикация высоты размещения
4. **Коллизии** - проверка на пересечение с другими объектами
5. **Отмена выделения** - подсветка зоны размещения
