# Обновление интерфейса игры: Кнопки "Станции" и "Добавить"

## Дата обновления
2026-03-08

## Изменения

### 1. Кнопка "🚀 Станции" (вместо "Производство")

**Расположение:** Нижнее меню игры, вторая кнопка слева

**Функционал:**
- Открывает меню со списком всех сохранённых станций
- Каждая станция отображается с кнопками "Разместить" и "Удалить"
- При нажатии "Разместить" станция появляется перед камерой в игре
- При нажатии "Удалить" станция удаляется из списка и с сервера

**Исходный код:**
- `src/client/main.ts` - метод `showStationMenu()`
- `src/ui/BuildMenu.ts` - кнопка `stationsBtn`

### 2. Кнопка "📥 Добавить" (вместо "Склад")

**Расположение:** Нижнее меню игры, третья кнопка слева

**Функционал:**
- Открывает диалог выбора JSON файла
- Загружает файл формата `.blueprint.json` в игру
- Сохраняет станцию на сервер через API `/api/stations`
- Автоматически обновляет меню станций после загрузки

**Поддерживаемые форматы:**
- `.json` - стандартный JSON файл
- `.blueprint` - файл чертежа

**Исходный код:**
- `src/ui/BuildMenu.ts` - методы `openFileLoader()` и `handleFileUpload()`

### 3. Меню станций

**Элементы управления:**
- Заголовок "🚀 Ваши станции"
- Список станций с кнопками:
  - **Разместить** - зелёная кнопка, размещает станцию перед камерой
  - **Удалить** - красная кнопка, удаляет станцию навсегда
- Кнопка "✕ Закрыть" - закрывает меню

**HTML элемент:**
```html
<div id="station-menu" style="display: none;">
    <div id="station-list"></div>
</div>
```

**Стили:** `public/css/style.css`

## Формат файла станции

```json
{
  "name": "MyStation",
  "version": "1.0",
  "voxels": [
    {
      "x": 30,
      "y": 32,
      "z": 30,
      "type": "hull_light"
```

## API Endpoints

| Метод | Endpoint | Описание |
|-------|----------|----------|
| GET | `/api/stations` | Получить список всех станций |
| GET | `/api/stations/:name` | Получить данные станции |
| POST | `/api/stations` | Сохранить новую станцию |
| PUT | `/api/stations/:name` | Обновить станцию |
| DELETE | `/api/stations/:name` | Удалить станцию |

## Примеры использования

### 1. Создание станции в конструкторе

1. Нажмите "🛠️ Конструктор" в игровом меню
2. Постройте станцию из вокселей
3. Нажмите "🚀 В игру"
4. Введите название и сохраните
5. Автоматический переход в игру

### 2. Загрузка JSON файла

1. Нажмите "📥 Добавить" в игровом меню
2. Выберите файл `.json` или `.blueprint.json`
3. Введите название станции
4. Станция сохранится и появится в меню

### 3. Размещение станции

1. Нажмите "🚀 Станции" в игровом меню
2. Найдите нужную станцию в списке
3. Нажмите "Разместить"
4. Станция появится перед камерой

## Важное примечание по запуску

**Ошибка 404/501 на API запросах означает, что запущен НЕ тот сервер!**

### Правильный запуск:

```bash
# 1. Остановите другие сервера (Python и т.д.)
pkill -f python
pkill -f http.server

# 2. Запустите наш сервер
cd /home/father/project/cosmocraft
npm run dev

# 3. Проверьте в логах:
# 🚀 Game server started on port 8080
# 📁 Static server started on port 8001
# 📁 API endpoints: /api/stations
```

### Неправильно (будет ошибка 404/501):
```bash
python -m http.server 8000  # ❌ Не поддерживает API
```
