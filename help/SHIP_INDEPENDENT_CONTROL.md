# Исправление управления кораблём - Полная независимость

## Дата исправления
2026-03-08

## Проблема (до исправления)

❌ **Корабль привязан к центру системы (0,0,0):**
- Стрелки вращали камеру вокруг звезды, а не вокруг корабля
- Кнопка "вверх" приближала к звезде, "вниз" отдаляла
- Корабль появлялся внутри звезды
- A/Z только меняли значение скорости, но не включали двигатели
- Мышь захватывалась (Pointer Lock), нельзя было управлять UI

## Решение

### ✅ Полностью переписан ShipController

**Новая логика:**

1. **Корабль имеет независимую позицию**
   ```typescript
   private shipPosition: THREE.Vector3;
   // Спавн: (500, 0, 0) - рядом со станцией, не в звезде!
   ```

2. **Корабль вращается вокруг СВОЕЙ оси**
   ```typescript
   private shipRotation: THREE.Euler;
   private shipQuaternion: THREE.Quaternion;
   
   // Стрелки влево/вправо вращают нос корабля
   if (ArrowLeft) shipRotation.y += rotationSpeed;
   if (ArrowRight) shipRotation.y -= rotationSpeed;
   ```

3. **A/Z включают двигатели**
   ```typescript
   private increaseThrottle() {
       this.throttle = Math.min(100, this.throttle + 10);
       // Тяга двигает корабль вперёд
   }
   ```

4. **Движение по направлению носа корабля**
   ```typescript
   const forward = new THREE.Vector3(0, 0, -1);
   forward.applyQuaternion(this.shipQuaternion);
   this.velocity.copy(forward.multiplyScalar(this.speed * deltaTime));
   this.shipPosition.add(this.velocity);
   ```

5. **Мышь свободна для UI**
   ```typescript
   // Pointer Lock удалён
   // Мышь вращает камеру независимо от корабля
   ```

## Архитектура

### До исправления:
```
Звезда (0,0,0) ← центр вращения
    ↑
Камера вращается вокруг звезды
    ↑
Корабль привязан к камере
```

### После исправления:
```
Корабль (независимая позиция)
    ├── Вращение вокруг СВОЕЙ оси
    ├── Движение по направлению носа
    └── Камера следует за кораблём
            └── Мышь вращает камеру независимо
```

## Физика движения

### Вращение корабля
```typescript
// Стрелки вращают нос корабля вокруг его оси
if (ArrowLeft) {
    this.shipRotation.y += rotationSpeed; // Влево
}
if (ArrowRight) {
    this.shipRotation.y -= rotationSpeed; // Вправо
}

// Обновляем кватернион
this.shipQuaternion.setFromEuler(this.shipRotation);
```

### Движение вперёд
```typescript
// Получаем направление носа корабля
const forward = new THREE.Vector3(0, 0, -1);
forward.applyQuaternion(this.shipQuaternion);

// Применяем скорость
this.velocity.copy(forward.multiplyScalar(this.speed * deltaTime));

// Двигаем корабль
this.shipPosition.add(this.velocity);
```

### Тяга двигателей
```typescript
// A увеличивает тягу
this.throttle = Math.min(100, this.throttle + 10);

// Вычисляем скорость
this.speed = (this.throttle / 100) * currentMaxSpeed;
```

## Проверка работы

### 1. Корабль не в звезде

После входа в игру:
- Корабль должен быть на позиции (500, 0, 0)
- Звезда должна быть в стороне

### 2. Вращение вокруг своей оси

```
1. Нажмите ← (стрелка влево)
2. Нос корабля должен повернуться влево
3. Звезда должна сместиться вправо (относительно носа)
```

### 3. Движение вперёд

```
1. Нажмите A несколько раз (тяга 30-50%)
2. Корабль должен лететь в направлении носа
3. Координаты должны меняться
```

### 4. Полёт сквозь звезду

```
1. Направьте нос на звезду
2. Включите тягу (A)
3. Корабль должен лететь прямо на звезду
4. Должен пролететь сквозь неё и улететь дальше
```

## Примечания

1. **Корабль независим** - имеет свою позицию, вращение, скорость
2. **Камера следует за кораблём** - вид от первого лица
3. **Мышь свободна** - можно управлять UI без захвата
4. **A/Z включают двигатели** - не просто меняют значение
5. **Стрелки вращают нос** - вокруг оси корабля, не звезды
6. **Спавн рядом со станцией** - не в центре системы
