## Система щитов

### Параметры

- **Начальные щиты:** 100%
- **Урон за столкновение:** -10%
- **Количество столкновений до уничтожения:** 10
- **Кулдаун после столкновения:** 1 секунда (неуязвимость)

## Столкновения

### Обнаружение

Столкновения обнаруживаются через Raycaster:
- Луч пускается из позиции корабля в направлении движения
- Длина луча: 10 единиц
- Проверяются пересечения с объектами сцены

### Типы объектов для столкновений

1. **Звезда** (`name === 'star'`)
2. **Астероиды** (`userData.type` существует)
3. **Станции** (`parent.userData.isStation`)

### Обработка столкновения

```typescript
private handleCollision() {
    // 1. Сброс скорости
    this.velocity.set(0, 0, 0);
    this.speed = 0;
    
    // 2. Снятие 10% щитов
    this.shields = Math.max(0, this.shields - 10);
    
    // 3. Проверка уничтожения
    if (this.shields <= 0) {
        this.respawn();
    }
    
    // 4. Кулдаун (1 секунда неуязвимости)
    this.collisionCooldown = true;
    setTimeout(() => {
        this.collisionCooldown = false;
    }, 1000);
}
```

## Респавн

### Условия

- Щиты упали до 0%
- 10 столкновений без восстановления

### Процесс респавна

```typescript
private respawn() {
    // Позиция: (500, 0, 0) - рядом со станцией
    this.shipPosition.set(500, 0, 0);
    
    // Вращение: сброшено
    this.shipRotation.set(0, 0, 0, 'YXZ');
    this.shipQuaternion.identity();
    
    // Скорость: сброшена
    this.velocity.set(0, 0, 0);
    this.throttle = 0;
    this.speed = 0;
    
    // Щиты: восстановлены
    this.shields = 100;
    
    // Камера: следует за кораблём
    this.camera.position.copy(this.shipPosition);
}
```

## Физика движения

### Вращение

```typescript
// Стрелки вращают нос корабля
const rotationSpeed = 0.05; // радиан за кадр

if (ArrowLeft)  shipRotation.y += 0.05; // Влево
if (ArrowRight) shipRotation.y -= 0.05; // Вправо
if (ArrowUp)    shipRotation.x += 0.05; // Нос вниз
if (ArrowDown)  shipRotation.x -= 0.05; // Нос вверх
```

### Движение

```typescript
// Направление носа
const forward = new THREE.Vector3(0, 0, -1);
forward.applyQuaternion(this.shipQuaternion);

// Применяем скорость
this.velocity.copy(forward.multiplyScalar(this.speed * deltaTime));

// Двигаем корабль (если нет столкновения)
this.shipPosition.add(this.velocity);
```
