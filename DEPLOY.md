# CosmoCraft - Инструкция по запуску

## Быстрый старт (локальная разработка)

```bash
# Установка зависимостей
npm install

# Сборка
npm run build

# Запуск сервера
node dist/server/GameServer.js

# Или в режиме разработки
npm run dev
```

Откройте в браузере: `http://localhost:8001`

---

## Запуск в production (через nginx)

### 1. Настройте сервер (10.222.0.21)

Запустите игровой сервер:
```bash
cd /home/father/project/cosmocraft
npm run build
node dist/server/GameServer.js
```

Сервер слушает:
- **8001** - HTTP (статические файлы + API)
- **8080** - WebSocket (игровое соединение)

Оба интерфейса слушают на `0.0.0.0` (доступны из локальной сети).

### 2. Настройте nginx (10.222.0.25)

Скопируйте конфиг `nginx.conf` из проекта:
```bash
scp nginx.conf root@10.222.0.25:/etc/nginx/sites-available/cosmocraft
```

Отредактируйте пути к SSL сертификатам в конфиге, затем:
```bash
ln -s /etc/nginx/sites-available/cosmocraft /etc/nginx/sites-enabled/
nginx -t
systemctl reload nginx
```

### 3. Подключение клиентов

Через nginx (единый порт 443):
```
https://cosmocraft.rupru.ru
```

Напрямую (локальная сеть):
```
http://10.222.0.21:8001
```

## Параметры URL

| Параметр | Описание | Пример |
|----------|----------|--------|
| `server` | Адрес WebSocket сервера | `?server=10.222.0.21` |
| `ws_path` | Путь для WebSocket (для nginx) | `?ws_path=/ws` |
| `renderDistance` | Дальность прорисовки астероидов | `?renderDistance=2000` |

### Примеры:

**Локально:**
```
http://localhost:8001
http://localhost:8001?renderDistance=1500
```

**Через nginx:**
```
https://cosmocraft.rupru.ru?ws_path=/ws
https://cosmocraft.rupru.ru?ws_path=/ws&renderDistance=2000
```

**Напрямую (локальная сеть):**
```
http://10.222.0.21:8001
http://10.222.0.21:8001?server=10.222.0.21
```

## Оптимизация

### Дальность прорисовки

По умолчанию: **3000** единиц

Меньше = лучше производительность:
- `?renderDistance=1000` - слабо (для слабых ПК)
- `?renderDistance=2000` - средне
- `?renderDistance=3000` - по умолчанию
- `?renderDistance=5000` - далеко (требует мощного ПК)

### Как это работает:

1. Клиент получает список всех астероидов от сервера
2. Рендерятся **только** астероиды в радиусе `renderDistance` от камеры
3. Для дальних астероидов используется упрощенная геометрия (меньше вокселей)
4. При движении камеры астероиды динамически добавляются/удаляются

## Структура портов

| Компонент | Порт | Протокол | Описание |
|-----------|------|----------|----------|
| nginx → клиенты | 443 | HTTPS/WSS | Единая точка входа |
| nginx → сервер | 8001 | HTTP | Статика + REST API |
| nginx → сервер | 8080 | WebSocket | Игровые события |
| сервер (локально) | 8001 | HTTP | Внутренний HTTP |
| сервер (локально) | 8080 | WebSocket | Внутренний WS |

## Troubleshooting

### Клиент не подключается к WebSocket

1. Проверьте, что сервер запущен: `ps aux | grep GameServer`
2. Проверьте порты: `ss -tlnp | grep -E "(8001|8080)"`
3. Для nginx: проверьте логи `/var/log/nginx/cosmocraft_error.log`

### Астероиды не отображаются

1. Откройте консоль браузера (F12)
2. Проверьте логи на наличие ошибок WebSocket
3. Уменьшите `renderDistance`: `?renderDistance=1000`

### Сервер падает

Проверьте логи:
```bash
tail -50 /tmp/cosmocraft.log
```

Проверьте подключение к БД:
```bash
mysql -u prusakoviv -p -e "USE cosmocraft; SELECT COUNT(*) FROM asteroids;"
```
